Annotation

A beginner's guide to the Java programming language, from its foundations to interactive web applications. In the first part of the book, the reader will gain knowledge of object-oriented programming concepts, an overview of data types, and useful methods of the standard language library, and will encounter terms necessary for building web pages. The second part of the book provides an explanation of the program constructs used against the background of the developed applications. Java has long been one of the most in-demand programming languages in the IT job market.
