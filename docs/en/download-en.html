Overview

A beginner's guide to the Java programming language—from fundamentals to interactive web applications. In the first part, readers learn object-oriented concepts, data types, and useful methods from the standard library, plus terms needed to build web pages. The second part explains the programming constructs used in the sample applications. Java has long been one of the most in-demand programming languages in IT.
