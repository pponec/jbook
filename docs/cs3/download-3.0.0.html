Pavel Ponec:
Učebnice jazyka

Java

a tvorba webových aplikací
pro samouky III

Anotace

Průvodce začátečníka programovacím jazykem Java od jeho základů až po interaktivní webové aplikace. V první části knihy čtenář získá znalost pojmů objektového programování, přehled o datových typech a užitečných metodách standardní knihovny jazyka, setká se s pojmy potřebnými pro stavbu webových stránek. Druhá část knihy přináší výklad použitých programových konstrukcí na pozadí řešených aplikací. Java patří dlouhodobě mezi nejžádanější programovací jazyky na trhu práce v oboru informačních technologií.
